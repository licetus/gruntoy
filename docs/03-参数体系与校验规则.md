## 1. 总览

| 项 | 值 |

| 组 | 名称 | 项数 | 内容 |

| `purr` | 咕噜（触发/降落/冷却/映射/体感） | 31 | 触发阈值、降落曲线、冷却、时长映射、驱动频率与占空比 |

| `sys` | 系统与调试 | 4 | 云端通道开关、调试模式、日志、性格预设 |
| | **合计** | **75** | |

### 1.2 单位约定（重要）

频率与比例类参数**一律用整数存储**，避免浮点误差在 NVS 往返后漂移：

| 类型 | 单位 | 示例 |
|---|---|---|
| 频率 | Hz × 100 | `30` = 0.30Hz，`200` = 2.00Hz，`3000` = 30Hz |
| 幅度/占空比 | 百分比 × 1，或归一化 × 100 | `65` = 65%，`60` = 0.60 |
| 时长 | 毫秒 | `20000` = 20s |
| 布尔 | 0 / 1 | — |
| 枚举 | 序号 | 见 §4 枚举型参数 |

> **注意 `purr_drive_freq_hz` 与摇尾频率的单位不同**：前者是「咕噜的驱动频率」，
> 单位 Hz×100，默认 `3000`（=30Hz）；后者是「摇尾摆频」，单位 Hz×100，
> `200` = 2.00Hz。两者数量级差 15 倍，因为它们分别作用在马达与机构上。

| `mood_max` | 120 | 100~999 | 上限（超出截断） |
| `mood_decay_floor` | 40 | 0~120 | 自然衰减下限（**不归零**） |
| `pet_gain_per_stroke` | 2 | 0~20 | 单次有效抚摸增量 |
| `pet_valid_min_ms` | 3000 | 500~10000 | 有效抚摸最短持续时长 |
| `pet_debounce_ms` | 500 | 100~3000 | 抚摸防抖间隔 |
| `pet_continuous_window_ms` | 30000 | 5000~120000 | 连续抚摸判定窗口 |
| `pet_continuous_bonus` | 1 | 0~10 | 连续抚摸额外增量 |
| `pet_continuous_interval_ms` | 10000 | 3000~60000 | 额外增量发放间隔 |
| `mood_decay_start_ms` | 1800000 | 0~7200000 | 无互动多久后开始衰减（30 分钟） |
| `mood_decay_interval_ms` | 300000 | 60000~1800000 | 衰减间隔（5 分钟） |
| `mood_decay_step` | 1 | 0~10 | 每次衰减量 |

| `purr_cumulative_limit_ms` | 300000 | 60000~1800000 | **累计连续运行上限**（闸门二） |

#### tiered 模式的映射形状

`D0`~`D3` 是分段线性曲线上的**四个锚点**（不是四个「档位值」）：

```
时长
120s ┤
     │
 60s ┤                                    ╭─────  D3 平台（b3~b4）
     │                              ╭─────╯
 46s ┤                        ╭─────╯  D2
     │                  ╭─────╯
 32s ┤            ╭─────╯  D1
     │      ╭─────╯
 20s ┤──────╯  D0
     └──┬────┬────┬────┬────┬──────►  心情值
       b0   b1   b2   b3   b4
      100  105  110  115  120
```

三条性质：

1. **端点为精确锚点** —— 调参时可精确指定首尾手感（阈值处 20s，最高处 60s）。
2. **全程无跳变** —— 这是修复 PoC 缺陷的核心：PoC 用「档内插值 + 档间跳变」，
   在 104→105 处单点跳变 10 秒，违反 FR-40 的平滑要求。
3. **`b3`~`b4` 段保持平台** —— 刻意设计选择。若继续外推就需要新增「终点时长」参数，
   会让 `D3` 的语义变模糊。平台是显式的取舍。

#### linear 模式

```
duration = purr_linear_intercept_ms + purr_linear_slope × (mood − purr_tier_b0)
```

结果截断到 `purr_duration_max_ms`。用于「想用一条公式快速试参」的场景，
不追求端点精确。

### 3.3 咕噜体感（组 D，5 项）

| 参数名 | 默认 | 区间 | 说明 |
|---|---|---|---|
| `purr_drive_freq_hz` | 3000 | 2000~6000 | **驱动频率（Hz×100）**，3000 = 30Hz |
| `purr_duty_base_pct` | 65 | 10~100 | 基础占空比 |
| `purr_duty_jitter_pct` | 15 | 0~50 | 强度抖动幅度 |
| `purr_jitter_period_ms` | 500 | 100~5000 | 抖动周期 |
| `purr_long_envelope_ms` | 15000 | 5000~60000 | 长包络缓变周期 |

**咕噜的最终波形 = 四层叠加**：

```
基础占空比 P-33
  × 强度抖动 P-34/P-35（短周期，约 500ms，产生「呼噜呼噜」的起伏）
  × 长包络 P-36（长周期，约 15s，产生整体渐强渐弱）
  × 淡入淡出 P-22/P-23（禁止骤起骤停）
  → 门控调制 P-32（把平均占空比切成 f 频率的通/断脉冲）
```

`purr_drive_freq_hz` 是 M1 Day5 扫频实验的主角：`t gate 25` ~ `t gate 50`，
每档贴近耳朵听 30s，找出「最像猫」的区间。

| `tail_stop_idle_ms` | 600000 | 0~3600000 | 无互动多久后停止摇摆（10 分钟） |

### 5.1 迟滞带（`tail_hysteresis`）防的是什么

没有迟滞时，心情值在分界点（如 99）附近小幅波动会导致档位反复跳变，
表现为尾巴「抽搐」。迟滞带 = 2 表示升档需超过分界 2 点、降档需低于分界 2 点。

### 5.2 `tail_stop_idle_ms` 不是「心情值归零」

无互动超过 10 分钟后**只是停止摇摆动作**，心情值不受影响。
区分「不动了」与「不高兴了」——前者省电，后者是情绪，两者不应混为一谈。

## 8. 校验规则全表（21 条）

所有写入先试算，违反即**拒绝**（不写入、不钳制）并回报规则号 + 人类可读说明。

### 8.1 `C-01`~`C-18`（源自 PRD 附录 C.8）

| 规则 | 约束 | 违反后果 |
|---|---|---|
| `C-01` | `mood_initial < purr_trigger_threshold` | 开机立即触发咕噜 |
| **`C-02`** | **`mood_restore_value < purr_trigger_threshold`** | **咕噜结束立即重触发 → 无限死循环** |
| `C-03` | `purr_duration_max_ms ≥ max(D0~D3)` | 时长被意外截断 |
| `C-04` | 分段点个数 = 时长个数 + 1 | 结构错位（本实现由编译期结构保证，运行时恒真） |
| `C-05` | 分段点严格递增且末值 = `mood_max` | 高档位永不触发 |
| `C-06` | `mood_decay_floor ≤ mood_restore_value` | 状态错乱 |
| `C-07` | `pet_gain_per_stroke > 0` 且 `pet_valid_min_ms > 0` | 无法累积 |
| `C-08` | `cooldown_duration_ms ≥ 0` | （由 min 钳制保证，恒真） |
| **`C-09`** | **`purr_drive_freq_hz ∈ [2000, 6000]`（20~60Hz）** | **马达不转或异响** |
| `C-10` | 摇尾分界/频率/幅度三组长度一致 | （结构固定为 4，恒真） |
| `C-11` | 摇尾分界严格递增且末值 = `mood_max` | W4 永不触发 |
| `C-12` | 摇尾各档频率 ≤ 300（3.0Hz） | 超机构允许摆频 |
| `C-13` | 摇尾各档幅度 ≤ 100（1.0） | 超出机械限位 |
| `C-14` | `tail_purr_exit_transition_ms ≥ tail_transition_ms` | 咕噜后过渡反而更快 |
| `C-15` | `mood_landing_ms > 0` | 退化为阶跃，违背平滑设计 |
| **`C-16`** | **`\|tail_purr_exit_transition_ms − mood_landing_ms\| ≤ 1000`** | **内外错位（摇尾降完了心情还没降完）** |
| `C-17` | `mood_landing_segments ≥ 3` | 缓入缓出无法体现 |
| **`C-18`** | **`breath_trough_duty_pct == 0`** | **低占空比机械嗡鸣** |

### 8.2 `X-01`~`X-03`（v1.0 新增扩展）

| 规则 | 约束 | 为何需要 |
|---|---|---|
| `X-01` | `purr_tier_b0 == purr_trigger_threshold` | 否则心情值刚达阈值时会映射到「中间档时长」，最低档 `D0` 永不生效 |
| `X-02` | 线性模式下 `slope > 0` 且映射在 `[阈值, mood_max]` 单调不减 | 防止映射无意义或反向 |
| `X-03` | 枚举型参数取值落在合法序号区间 | 防止非法序号进入状态机 |

### 8.3 通用错误码

| 码 | 含义 |
|---|---|
| `E-RANGE` | 参数编号越界（内部错误） |
| `E-LIMIT` | 取值超出该参数允许区间（`GET <param>` 可见 `[min~max]`） |

### 8.4 关于「拒绝」而非「钳制」

`validateSet()` **不预先钳制候选值**，而是以原值试算整套规则。

**为什么**：若先钳制再校验，越界值会被悄悄夹进合法区间，规则永远报不出来。
典型后果是 `t gate 99`（超出 20~60Hz 工作区间）看起来设置成功，实际被夹到 60Hz——
操作者据此测出的「猫感区间」是错的。因此值域类约束优先以 `C-09` 等具体规则报出，
无规则覆盖的越界值报 `E-LIMIT`。

> 注意区分：`Params::set()`（内部写入）**仍然钳制**，因为它用于加载 NVS 与预设应用；
> `validateSet()`（外部试写）**不钳制**，因为它要回答「这个值能不能用」。

### 9.1 预置的语义梯度

| 维度 | gentle → lively 的变化 | 用户感受 |
|---|---|---|
| 触发阈值 | 105 → 95 | 更容易被摸到咕噜 |
| 冷却时长 | 2min → 1min | 更快「缓过来」 |
| 咕噜强度 | 55% → 70% | 咕噜更有力 |
| 呼吸节流 | 45s → 20s | 更频繁地「呼吸」 |
| 摇尾频率（各档） | 全部提高约 30% | 尾巴动得更欢 |

### 9.2 预置实现的两处约束

1. **分段点随阈值整体左移**：`purr_tier_b0` 必须与阈值同步（`X-01`），
   因此预设改动阈值时必须一并改 `b0`——否则 `applyPreset()` 会校验失败并拒绝应用。
2. **两个「末值 = `mood_max`」的分段点自动同步**：`purr_tier_b4` 与 `tail_tier_b3`
   在预设应用后强制置为 `mood_max`（`C-05` / `C-11` 强制）。

> `applyPreset()` 在应用前会跑一次完整 `validate()`；若失败则**拒绝应用**并打印
> 违反的规则号，不会留下半改状态。`standard` 预设的自洽性由 `test_main.cpp` 的
> 「三套预设自洽」段落守护。
